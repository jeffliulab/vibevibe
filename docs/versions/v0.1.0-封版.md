### 决策

- **走 CPU 不走 GPU**:CTranslate2 在 Blackwell(sm_120)用 int8 会崩;
  且不占显存意味着跑 Isaac Lab / CARLA 时听写照样能用
- **1.7B 而不是 0.6B**:准确率差一档,RTF 从 0.08 涨到 0.15 仍远快于实时
- **音频预处理默认关闭**:受控实验证明它对 0.6B 有效(英文 WER 0.774→0.309),
  但对 1.7B 略有害。收益是模型特异的,不是普适的
- **不加热词表**:换更大模型是更根本的解法,热词是维护负担且只覆盖列进去的词
- **托盘独立进程**:否则"关掉服务"会把托盘自己也关掉

### 踩过的坑

- 卸载模型后内存不还给系统 —— 光 `del` + `gc` 只降到 3306 MB,
  必须额外调 `malloc_trim(0)` 才真正降到 306 MB(glibc 把 free 的内存
  扣在自己 arena 里)
- 削顶重建第一版把信噪比搞坏 20dB:重建上限写成了绝对值而非相对阈值
- 第二版更糟(-145dB):拿绝对样本下标做三次拟合,数值条件数爆炸
- 受控实验本身也错过一次:拿"已削顶录音 × 0.4"当基准真值,真值本身就是平顶的
- 1.7B 的 `embed_tokens.bin` 是 float16 而非 float32 —— 按 float32 读
  不报错,只会安静地输出乱码。靠文件大小反推才发现
