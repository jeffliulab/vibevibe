# v0.3.0 开发日志(开发中)

目标:Wayland 支持 + 上下文偏置(治剩下那几个专有名词)

## 2026-07-26

### 完成

- 小键盘拔插复验通过:读回 `(0,0)=0x006E KC_F19` / `(0,1)=0x0028 KC_ENTER`,
  跟拔插前一致 —— 键位存在板子自己的 EEPROM 里,是板载记忆而非驱动层改键

### 决策

- **判断一块 macropad 是不是真 VIA,看 hidraw 上有没有 `UsagePage 0xFF60`,
  不看主控型号。** 原来认定「CH552 是 8051 内核、QMK 不支持,所以那类货
  只能配 Windows 上位机」,但买到的样品恰恰是 CH55x 且跑的是真 VIA。
  凭主控型号先入为主会错过能用的货。

### 遗留

- 读设备时**不能写死 hidraw 编号** —— 拔插后会变。已在验证脚本里改成
  按 `0xFF60` 签名动态查找,将来若把改键工具收进项目要沿用这个做法。
